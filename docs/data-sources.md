이 저장소는 두 갈래 자료를 함께 씁니다. 사업장 명단·품목 검색(`index.html`, `offers.html`)과 종합쇼핑몰 단가 카탈로그(`catalog.html`)는 모두 **사업자등록번호**로만 결합합니다.

# 사업장 명단 자료 (index.html · offers.html)

사업장 명단은 가치장터 인증 사회적기업 누적 명단(2026년 2차, 2026-07-14 수정)과 사용자가 제공한 `2026년 6월 30일 기준 정부권장정책.xlsx`를 사용합니다.

- 사회적기업: 사업내용, 업종, 사업자번호, 인증번호, 대표자, 대표전화번호, 소재지, 홈페이지를 수집합니다.
- 중증장애인생산품 생산시설: 생산품목, 시설명, 생산시설장, 전화번호, 생산시설 주소, 지정 유효기간을 수집합니다.
- 여성기업·장애인기업·창업기업: 사업자번호와 대표자, 확인 기간을 대조합니다.
- 장애인표준사업장·사회적협동조합: 사업자번호로 추가 유형을 대조합니다.

공개된 대표자명·사업장 연락처·상세주소는 구매 담당자의 업체 확인, 연락, 방문에 필요한 정보이므로 수집·표시합니다. 일괄 수집 금지 항목이 아닙니다. 생산시설장은 대표자와 구분합니다. 원문에 없는 정보는 만들어 채우지 않습니다. 자료 결합은 사업자등록번호를 기준으로 하며, 동명 업체나 대표자 이름만으로 합치지 않습니다.

검색 대상은 실제 사업내용이나 생산품목을 확보한 업체입니다. 여성기업 등 전체 명단을 모두 품목 검색할 수 있는 것은 아닙니다. 전체 명단 대조 건수와 검색 가능 건수는 화면의 자료 범위에 따로 표시합니다.

원본에 적힌 취소일·유효기간을 적용하며, 날짜가 없는 인증을 실시간 유효 인증으로 단정하지 않습니다. 인증 변경 공고 수집 결과도 업체 상태에 자동 반영하지 않고 검토 자료로 제공합니다.

공개 JSON은 원본 출처, 기준일, 원본 SHA-256과 생성일을 보관합니다. 인증키와 원본 파일은 저장소에 포함하지 않습니다.

### 2. 연락처 게시 원칙

구매 담당자가 동명 사업체를 구분하고 실제로 연락·방문할 수 있어야 하므로 **사업자등록 공개정보는 싣습니다.**
1. **대표자·시설장**: 엑셀의 `대표자명`·`생산시설장`을 싣고, 나라장터 업체 기본정보(`ceoNm`)가 있으면 그 값을 우선합니다.
2. **사업장 전화·팩스·홈페이지**: 나라장터 업체 기본정보(`telNo`, `faxNo`, `hmpgAdrs`)와 중증 시트 `전화번호`.
3. **사업장 주소**: 나라장터 업체 기본정보(`adrs`+`dtlAdrs`), 중증 시트 `생산시설의 주소`, 표준사업장 `소재지`. 광역 시도는 별도 `region`으로도 보존합니다.
4. **싣지 않는 것**: 계약담당자 개인 이름·이메일(`cntrctOfclNm`, `cntrctOfclEmail`), 개인 휴대전화.

출처 구분은 `contactSource`(`api` = 나라장터 업체 기본정보, `excel` = 정부권장정책 목록)로 남깁니다.
